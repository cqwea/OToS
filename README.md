# OToS Linux

### A second life for your hardware. Better place for makers.

OToS is an open-source lightweight linux distribution to make older hardware useful again while 
providing a better environment for makers,developers and hardware enthusiasts.

Built on Debian, OToS aims to combine low system resource usage 
with a approacheable desktop experience and tools for electronics development 
programming and digital fabrication

## OUR MISSION

We believe older hardware shouldnt become obsolete 
simply because newer operating systems demand more resources.

OToS Aims to :

- Give older hardware and low end computers a new life
- Provide lightweight and responsive desktop experience 
- Make Linux more approachable from people converting from other operating systems
- Make electronic development easier
- Bring essential maker tools into one accessible environment


## Core principles

1. Lightweight

Keep background resource usage low, prioritize responsiveness and make efficient use of available hardware.

2. Maker-Focused

Provide an environment for electronics, programming, CAD, 3D printing and hardware development.

3. Beginner-Friendly

Make everyday Linux tasks accessible without requiring users to learn terminal commands.

4. Open Source

Build transparently, welcome contributions and encourage community-driven development.

## Contributing

OTOS is a community-driven open-source project.

We welcome developers, designers, testers, documentation writers and hardware enthusiasts.
