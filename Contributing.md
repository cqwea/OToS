# CONTRİBUTİNG TO OToS
First of all thank you for your interest in contributing the OToS Project!

OToS is a lightweight linux based operating systems thats designed to give old hardware a second life and making hardware development and digital fabrication easier.

And we welcome linux enthuiasts, designers, testers , documentation writers and anyone interested in the project and want to help the project development.

## How Can You Contribute To OToS Project?
You dont need to be a software/Linux developer to contribute heres some areas that you can contribute:

 Operating System : Debian configuration, package selection, system optimization and desktop integration.
 Performance : Boot time, memory usage, CPU usage and resource optimization.
 Hardware Compatibility : Testing Wi-Fi, Bluetooth, USB devices, development boards and other hardware.
 Documentation : Installation guides, troubleshooting, tutorials and technical documentation.
 Design : Desktop appearance, icons, wallpapers and user experience.
 Testing : Finding bugs, reproducing issues and testing new builds.

## Before You Start
Before contributing, make sure you:

**Read the project's README.**
**Check existing issues to avoid duplicating work.**
If you're unsure about something, open an issue before starting major changes.

## Making changes 

Keep changes focused and easy to review.
Some guidelines:
1.Follow the existing project structure.
2.Write clear and understandable code.
3.Avoid unnecessary dependencies.
4.Test your changes before submitting them.
5.Document important changes when necessary.

## Reporting Bugs

When reporting a bug, include as much useful information as possible:

* OToS version or build.
* Hardware specifications.
* Steps to reproduce the issue.
* Expected behavior.
* Actual behavior.
* Relevant logs or screenshots.
* A detailed bug report makes troubleshooting much easier.
